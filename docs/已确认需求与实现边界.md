# 当前需求基线（1.2.8，2026-10-18）

本文整合用户截至本轮的最新确认，取代旧版固定90秒、尚无反馈等阶段假设；旧验收报告仅为历史证据。

## 设备和同步
- 30小室，A组1—15、B组16—30，两电压表、整组单路0—250A电流，两组各自的脉冲控制器。
- 电压沿用原代码：Modbus RTU，9600/8N1、站号1、FC03地址0x2A读4寄存器，首32位大端浮点。电流FC03地址0x56读1寄存器，raw/10000*250A。
- 控制器RS485按说明书读取参数11—14及状态22—27，默认9600/8E1、FC03、地址不偏移、倒计时0.01秒；可选FC04、地址-1、0.1秒倒计时。低层默认解释尚需真机对照确认。
- 左右组独立根据通道、周期与递减倒计时确认实际输出；绿色灯及文字显示当前测量小室。等待、掉线、冻结、过期或无法确认时不显示可靠接通。
- 输出阶段实际接通。默认输出6秒、有效[2,4)秒；软件可设置输出0.01—99.99秒和0≤起始<结束≤输出时长（0.01秒精度），恢复默认。
- 控制器端由操作者手动设置相同输出宽度和15路，软件仅读取核对，不写设备参数。路间/周期间隔额外计算，不固定整轮90秒；控制器波特率至少4800且实际请求跨度须≤0.2秒。
- 人工兼容模式仅显式选择，在1/16接通时手动同步，按所设时长推算，不在控制器故障时自动回退。

## 采样与统计
- 1Hz；电压每次请求的完整起止及不确定性必须在有效窗口，前后为同通道同周期的独立状态证据。跨边界、缺少状态、冻结或错误均保留无效尝试，不进入有效统计。
- 电流全程记录。全部规定有效读数保存；窗口短或通信故障时可能零有效样本，禁止补造。
- 每室最新值为最近有效样本，累计平均为本实验该室全部有效样本平均。新实验重置，旧历史保留。
- 总压从首个已测小室开始sum各室最新值，同室新读数替换。未齐全为部分合计；故障或旧值保留合计并提示质量。
- 控制器模式旧值判断按各组16×输出宽度+15×路间隔+周期间隔，人工模式16×输出宽度。电流读失败或超过2.5秒时当前值和实时功率不可用。
- 功率kW=可用总压V×有效整组电流A/1000。总压均值、平均功率在每个到达的实验整数秒按可用数值累计，跳秒不补数，界面刷新不重复统计；属于离散采样均值，不是连续积分。电压来自轮询，非30室同时采样。

## 界面与数据
- 居中标题重庆大学电解水制氢系统；左1—15右16—30，编号/最新电压/累计平均。30指示灯与两页文字显示当前小室，进度X/30。
- 底部整组电流、总压、总平均压、功率kW、平均功率；缺测留空，不补0。
- 趋势页33图，名称/编号/范围/组别筛选，点击放大并实时更新；真实故障缺测处断线，正常轮询非有效窗口不生成读数点。实时缓存2000点、日志300条，完整历史在SQLite。
- 参数设置、开始/停止、保存数据、历史查询；串口默认COM1电压A、COM2电压B、COM3电流及COM4/5控制器，实际接口必须按转换器配置。手动设置上下限，0阈值有效，超限仍保存原数值。
- 当前页TXT/真正xlsx导出；历史按实验/带时区时间/小室或电流/有效性筛选，分页与后台导出，保留原始控制证据及参数口径。
- 清空历史二次确认，运行、停止排队及导出时禁止；单事务删除会话和四类明细，失败回滚；不删除已导出文件、参数、日志、恢复或维护备份。

## 停止、异常与交付
- 启动仅待机，无模拟模式，不打开串口；采集在每物理总线隔离进程。
- 点击停止显示“正在停止读取”，读取全部退出后显示“正在保存数据”，完成才恢复“待机”；并行通知退出，串口3秒宽限后取消仍阻塞进程。已传回的完整包和尾部全部处理，待定电压逐包判定，坏包另存恢复证据，后台排空写库，完成才待机/允许新实验。
- 退出复用异步停止，导出结束才关闭。停止中错误进入最终状态，优先级error>interrupted>completed；不能忽略收尾失败而冒充成功。
- 数据失败明确报错、保留恢复文件；恢复写盘不持界面依赖的共享锁、临时写完同步后替换。恢复文件需人工核对，未提供自动导回。
- 交付自带依赖安装包、源代码/离线依赖、许可证、使用说明、用户当前Word项目方案及验收证据。目标Windows10 1809+/11 x64，不承诺Win7/8、32位或ARM。
- 软件侧检查不能代替真实仪表协议/量程、线路映射、实际继电器/阀门动作、测量缓存延迟、目标电脑安装及真实24小时连续运行验收。

- 1.2.4界面修订：顶部统一显示五路接口（电压A/电压B/电流/控制器A/控制器B）及实际配置COM号，使用相同的状态文字和颜色；人工兼容模式的控制器显示“未启用”。底部故障提示横条删除，故障/超限仍由运行事件和完整历史保存。


## 1.2.5 报警通知与实时显示

- 新出现的超限、仪表断线/过期、控制器状态异常弹出非模态报警窗口，同时播放随软件附带的提示音；未确认时每3秒重复一次。
- 多条报警合并在同一窗口。同一持续报警不反复弹窗；确认按钮或关闭弹窗均停止当前声音，但不修改故障判定，也不停止采集。顶部“报警”按钮可重新查看。
- 所有报警恢复后提示关闭；恢复后再次出现或新增其他报警会重新提醒。停止采集后消音，停止前报警仍可查看；新实验重新开始报警判定。
- 电流超限后出现断线或过期，只记录“状态无法判定”，不能把缺测当成恢复正常。
- 声音采用Windows异步PlaySound及内置WAV，不阻塞Qt事件循环；需要电脑有可用扬声器且音量未静音，软件不能保证物理扬声器实际发声。
- 弹窗打开时，最新有效电压、电流、累计均值、部分总压和功率仍实时更新。电流失效时实时电流和功率留空；旧电压保留并提示质量；无效区间不计入电压结果。


## 1.2.6 报警间隔与窗口释放（2026-10-18）

- 报警窗口顶部固定为“请检查设备和测量数值”，唯一按钮为“确认”。确认或关闭弹窗会消音并隐藏提示；采集、显示和记录继续，仍可从顶部报警入口查看。音频播放失败的诊断列在详细信息中。
- 输出结束至下一条状态、正常换路的首次确认、路间和周期间等待均不报警；这些阶段也不延长电压有效窗口或显示可靠接通灯。真实读取失败、参数错误、冻结、倒计时不相容、通信超时仍报警。
- 首次启动允许最多3秒等待第一条控制状态；已收到的明确错误立即提示。开始通信后超过0.6秒没有新控制状态，或换路状态持续超过0.6秒仍无法确认，按异常处理。
- 修复参数窗口关闭后Qt信号闭包保留控件的累积：确认、取消、标题栏关闭以及保存失败均在返回后销毁窗口。实时曲线、日志、控制状态仍采用有界缓存；完整样本在SQLite。

## 1.2.8 本轮复核（2026-10-18）

- 补齐仪表无响应监测：真实采集开始后三秒仍没有任何读取结果会报警；之后默认超过2.5秒没有读取完成包会报警。仪表读取超时配置较长时，监测上限取max(2.5秒, 配置超时+1.5秒)，以免合法请求未完成便误判。电流读数可用性仍独立遵守2.5秒规则。
- 无响应时对应COM卡显示“连接断开”，旧电压保留并标记质量；未收到新电流时当前电流和功率不可用。只有取得真实读取包才恢复响应状态；不生成缺测样本，不自动控制现场装置。
- 读取失败与无响应合并为同一设备报警，避免重复记账。正常采样窗口外的读取同样可以证明通信响应。
- 控制器正常等待仍不报警，但其读取跨度超过0.2秒属于通信异常，不能被“正常间隔”分支掩盖。
- 新增初次请求阻塞、运行中静默、合法长超时和历史入口重复关闭的回归验证；原始停止屏障、有效窗口和计算口径保持不变。

- 1.2.8导出复核：控制记录除原始寄存器外，显式保留interval_remaining及cycle_remaining，路间/周期间倒计时列可直接查看。
